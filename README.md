# 🚗 Mall Parking Management & Analytics System

## 📌 Problem Statement

Many parking facilities still rely on manual tickets or basic parking systems, making it difficult to track parking slots, calculate parking fees accurately, and analyze parking usage patterns.

This project aims to automate the parking process while providing useful business insights through analytics.

## 🎯 Solution

The Mall Parking Management System automatically:

- Assigns available parking slots
- Records vehicle entry and exit details
- Calculates parking fees based on parking duration
- Updates slot availability in real time
- Stores records in SQL Server
- Generates analytics dashboards for decision-making

## 🚀 Features

✅ Vehicle Entry Management  
✅ Vehicle Exit Management  
✅ Automatic Slot Allocation  
✅ Parking Fee Calculation (₹20/hour)  
✅ Parking Records Management  
✅ Dataset Download (CSV)  
✅ Analytics Dashboard

## Dashboard Analytics

- Total Vehicles Parked
- Total Revenue Generated
- Average Parking Fee
- Vehicle Type Distribution
- Peak Parking Hours
- Revenue Trends
- Recent Parking Activity

## Project Workflow

1. Vehicle enters parking area.
2. System assigns an available slot.
3. Entry time is recorded.
4. Parking fee is calculated based on duration.
5. Slot becomes available after exit.
6. Data is analyzed through an interactive dashboard.
